1. Display Distribution Analysis & Recommendations

1.1 Available Displays

Display Resolution Interface Characteristics Best Use
ST7796 480x320 SPI Large, landscape, RGB565, high resolution Primary cluster, detailed information
GC9A01 240x240 SPI Circular, medium size, RGB565 Gauges, secondary info, aesthetics
SSD1306 128x64 I2C Monochrome OLED, very low power Simple icons, always-on indicators

1.2 Telltales Display Decision

Option A: SSD1306 (Monochrome OLED)

✓ Pros:

  • Ultra-low power consumption (~20mW)
  • Can stay on 24/7 without draining battery
  • High contrast, visible in all lighting
  • Cheap ($3-5)
  • Simple to implement (I2C)
  • Perfect for simple icon-based warnings

✗ Cons:

  • No color (can't show severity via color)
  • Small size limits number of icons
  • Limited to ~10-12 icons at once

Option B: Small Color TFT (e.g., ST7735 128x160)

✓ Pros:

  • Color coding (red/yellow/green)
  • More flexible layouts
  • Can show text + icons
  • Better aesthetics

✗ Cons:

  • Higher power consumption (~100mW)
  • Needs backlight (drains battery)
  • More expensive ($8-12)
  • Requires another SPI channel

Recommendation: Use SSD1306 for MVP

Reasoning:

  • Telltales should be always visible - even when truck is off
  • Low power is critical for safety warnings (parking brake, door open, etc)
  • Color is "nice to have" but not essential - icon shape conveys meaning
  • Can upgrade to color TFT in v2.0 if needed

Alternative for more icons: Use SSD1309 (128x64, same as SSD1306 but better driver) or SSD1322 (256x64, grayscale) for more space.

4. Figma/GIMP to LVGL Complete Tutorial

Complete Workflow: Design → Code

Step 1: Design in Figma

  1. Create a new Figma file
  2. Create frames for each display:
    • ST7796: 480x320 frame (landscape)
    • GC9A01: 240x240 frame (square/circular mask)
    • SSD1306: 128x64 frame (black background, white elements)
  3. Design your HMI using Figma's built-in shapes and text
  4. Use components for reusable elements (icons, buttons)
  5. Export individual assets:
    • Select element → Right-click → Export → PNG
    • Choose resolution (1x, 2x, etc)
    • Name clearly: icon_battery.png, gauge_speed.png

Step 2: Edit/Optimize in GIMP (if needed)

  1. Open exported PNG in GIMP
  2. Adjust colors, contrast, transparency
  3. For RGB565 displays:
    • Image → Mode → RGB (if not already)
    • Colors → Levels → Adjust to compensate for color depth loss
  4. For SSD1306 (monochrome):
    • Image → Mode → Grayscale
    • Colors → Threshold → Convert to pure black/white
  5. Export as PNG

Step 3: Convert to LVGL Format

Method A: Online LVGL Image Converter (Easiest)

  1. Go to https://lvgl.io/tools/imageconverter
  2. Upload your PNG file
  3. Select settings:
    • Color format: RGB565 for ST7796/GC9A01, or Raw for SSD1306
    • Output format: C array
  4. Click "Convert"
  5. Download the .c file

Method B: Python Script (For Batch Processing)

#!/usr/bin/env python3 from PIL import Image import sys def png_to_c_array(png_file, output_name): img = Image.open(png_file) img = img.convert('RGB') width, height = img.size pixels = list(img.getdata()) # Convert to RGB565 rgb565_data = [] for r, g, b in pixels: rgb565 = ((r & 0xF8) << 8) | ((g & 0xFC) << 3) | (b >> 3) rgb565_data.append(rgb565) # Generate C file with open(f"{output_name}.c", 'w') as f: f.write(f"#include \"lvgl.h\"\n\n") f.write(f"const uint16_t {output_name}_map[] = {{\n") for i, pixel in enumerate(rgb565_data): if i % 10 == 0: f.write("\n ") f.write(f"0x{pixel:04X}, ") f.write("\n};\n\n") f.write(f"const lv_img_dsc_t {output_name} = {{\n") f.write(f" .header.cf = LV_IMG_CF_TRUE_COLOR,\n") f.write(f" .header.w = {width},\n") f.write(f" .header.h = {height},\n") f.write(f" .data_size = {len(rgb565_data) * 2},\n") f.write(f" .data = (uint8_t*){output_name}_map,\n") f.write(f"}};\n") if __name__ == "__main__": png_to_c_array(sys.argv[1], sys.argv[2])

Usage:

python3 png_to_c.py icon_battery.png img_battery # Generates: img_battery.c

Step 4: Integrate into NuttX Project

  1. Copy generated .c files to apps/hmi_manager/uiux/images/
  2. Create header file images.h:
    #ifndef __IMAGES_H #define __IMAGES_H #include "lvgl.h" /* Declare all images */ extern const lv_img_dsc_t img_battery; extern const lv_img_dsc_t img_temperature; extern const lv_img_dsc_t img_warning; /* ... add more */ #endif
  3. Use in widgets:
    #include "images.h" /* Create image object */ lv_obj_t *img = lv_img_create(parent); lv_img_set_src(img, &img_battery); lv_obj_align(img, LV_ALIGN_CENTER, 0, 0);
  4. Update Makefile to compile image files

4.1 Complete Example: Battery Icon

/* File: apps/hmi_manager/uiux/widgets.c */ #include "images/images.h" void widgets_create_battery_indicator(lv_obj_t *parent) { /* Create container */ lv_obj_t *cont = lv_obj_create(parent); lv_obj_set_size(cont, 100, 60); /* Add battery icon */ lv_obj_t *icon = lv_img_create(cont); lv_img_set_src(icon, &img_battery); lv_obj_align(icon, LV_ALIGN_TOP_MID, 0, 5); /* Add percentage label */ lv_obj_t *label = lv_label_create(cont); lv_label_set_text(label, "85%"); lv_obj_align(label, LV_ALIGN_BOTTOM_MID, 0, -5); }

5. Creating Animations for LVGL

5.1 Types of Animations

Animation Type Use Case Implementation
Property Animation Fade in/out, move, scale, rotate LVGL lv_anim API
Image Sequence Sprite animation, loading spinner Array of images + timer
Gauge Needle Speedometer, tachometer LVGL meter widget or custom arc
Progress Bar Battery charging, loading LVGL bar widget with animation
Blinking Icon Turn signals, warnings Toggle visibility with timer

5.2 Example: Fade-In Animation

void animate_fade_in(lv_obj_t *obj) { lv_anim_t a; lv_anim_init(&a); lv_anim_set_var(&a, obj); lv_anim_set_values(&a, 0, 255); /* From transparent to opaque */ lv_anim_set_time(&a, 500); /* 500ms duration */ lv_anim_set_exec_cb(&a, (lv_anim_exec_xcb_t)lv_obj_set_style_opa); lv_anim_start(&a); }

5.3 Example: Speedometer Needle Animation

static lv_obj_t *speed_meter; static lv_meter_indicator_t *speed_needle; void widgets_create_speedometer(lv_obj_t *parent) { /* Create meter widget */ speed_meter = lv_meter_create(parent); lv_obj_set_size(speed_meter, 200, 200); /* Add scale 0-120 km/h */ lv_meter_scale_t *scale = lv_meter_add_scale(speed_meter); lv_meter_set_scale_range(speed_meter, scale, 0, 120, 240, 135); /* Add needle */ speed_needle = lv_meter_add_needle_line(speed_meter, scale, 4, lv_color_red(), -10); /* Set initial value */ lv_meter_set_indicator_value(speed_meter, speed_needle, 0); } void widgets_update_speed_animated(int new_speed) { /* Smooth animation to new value */ lv_anim_t a; lv_anim_init(&a); lv_anim_set_var(&a, speed_needle); lv_anim_set_values(&a, lv_meter_get_indicator_value(speed_meter, speed_needle), new_speed); lv_anim_set_time(&a, 300); /* 300ms smooth transition */ lv_anim_set_exec_cb(&a, (lv_anim_exec_xcb_t)lv_meter_set_indicator_value); lv_anim_start(&a); }

5.4 Example: Blinking Turn Signal

static lv_obj_t *left_signal_icon; static lv_timer_t *blink_timer; static bool blink_state = false; void blink_timer_cb(lv_timer_t *timer) { blink_state = !blink_state; if (blink_state) { lv_obj_clear_flag(left_signal_icon, LV_OBJ_FLAG_HIDDEN); } else { lv_obj_add_flag(left_signal_icon, LV_OBJ_FLAG_HIDDEN); } } void widgets_enable_left_signal(bool enable) { if (enable) { /* Start blinking at 1Hz (500ms on, 500ms off) */ blink_timer = lv_timer_create(blink_timer_cb, 500, NULL); } else { /* Stop blinking, hide icon */ if (blink_timer) { lv_timer_del(blink_timer); blink_timer = NULL; } lv_obj_add_flag(left_signal_icon, LV_OBJ_FLAG_HIDDEN); } }

5.5 Example: Image Sequence Animation (Loading Spinner)

/* Create spinner frames in Figma/GIMP: spinner_00.png, spinner_01.png, ... spinner_07.png (8 frames, 45° rotation each) */ const lv_img_dsc_t *spinner_frames[] = { &img_spinner_00, &img_spinner_01, &img_spinner_02, &img_spinner_03, &img_spinner_04, &img_spinner_05, &img_spinner_06, &img_spinner_07, }; static uint8_t current_frame = 0; static lv_obj_t *spinner_img; static lv_timer_t *spinner_timer; void spinner_timer_cb(lv_timer_t *timer) { current_frame = (current_frame + 1) % 8; lv_img_set_src(spinner_img, spinner_frames[current_frame]); } void widgets_show_loading_spinner(lv_obj_t *parent, bool show) { if (show) { spinner_img = lv_img_create(parent); lv_img_set_src(spinner_img, spinner_frames[0]); lv_obj_align(spinner_img, LV_ALIGN_CENTER, 0, 0); /* Animate at 12 FPS (83ms per frame) */ spinner_timer = lv_timer_create(spinner_timer_cb, 83, NULL); } else { if (spinner_timer) { lv_timer_del(spinner_timer); spinner_timer = NULL; } if (spinner_img) { lv_obj_del(spinner_img); spinner_img = NULL; } } }
Performance Tip: Keep animations simple on embedded systems. Avoid:
  • Too many simultaneous animations (max 2-3)
  • Very high frame rates (30 FPS is overkill, 10-15 FPS is enough)
  • Large image sequences (keep frames small or use fewer frames)
  • Complex easing functions (linear or simple ease-in-out is fine)

telltales[2].img = &img_temperature; telltales[3].img = &img_gear; telltales[4].img = &img_door; telltales[5].img = &img_parking_brake; telltales[6].img = &img_charging; telltales[7].img = &img_lights; 6.3 Integration with CAN Messages

/* File: apps/hmi_manager/app_hmi_manager.c */ static void process_can_frame(struct can_frame *frame) { uint32_t id = frame->can_id & CAN_EFF_MASK; int ret; /* Battery voltage → Low battery telltale */ if (id == CAR_CAN_SYSTEM_VOLTAGES_FRAME_ID) { struct car_can_system_voltages_t msg; ret = car_can_system_voltages_unpack(&msg, frame->data, frame->can_dlc); if (ret == 0) { double voltage = car_can_system_voltages_meas_batt_voltage_decode( msg.meas_batt_voltage); /* Update main display */ widgets_set_voltage((int)(voltage * 10.0)); /* Check for low battery (< 20% assumed at 40V) */ if (voltage < 40.0) { telltales_show_battery_low(true); } else { telltales_show_battery_low(false); } } } /* Temperature → High temp telltale */ else if (id == CAR_CAN_INVERTER_TEMP_FRAME_ID) { struct car_can_inverter_temp_t msg; ret = car_can_inverter_temp_unpack(&msg, frame->data, frame->can_dlc); if (ret == 0) { double temp_u = car_can_inverter_temp_inverter_temp_u_decode( msg.inverter_temp_u); /* Check for high temperature (> 80°C) */ if (temp_u > 80.0) { telltales_show_temperature(true); } else { telltales_show_temperature(false); } } } /* Faults → Fault telltale */ else if (id == CAR_CAN_INVERTER_FAULTS_FRAME_ID) { struct car_can_inverter_faults_t msg; ret = car_can_inverter_faults_unpack(&msg, frame->data, frame->can_dlc); if (ret == 0) { /* Any active fault? */ if (msg.flh_active_faults != 0) { telltales_show_fault(true); telltales_show_warning(true); } else { telltales_show_fault(false); telltales_show_warning(false); } } } }
